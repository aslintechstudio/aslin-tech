# Lumvelina Studio — Portföy Demo Sitesi

Aslin Tech tarafından geliştirilen, tamamen kurgusal bir güzellik stüdyosu web sitesi.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. Fotoğraflar yerel assets klasöründedir; Google Fonts yazı tipleri internet bağlantısı gerektirir.

## Özellikler
- Türkçe, mobil uyumlu tasarım
- Cilt bakımı, makyaj ve spa hizmetleri
- Hizmet, tarih ve saat seçilebilen **demo randevu** formu
- Form hiçbir bilgiyi sunucuya göndermez ve saklamaz; gerçek randevu oluşturmaz
- Stok fotoğraflar temsili görsellerdir

## Dosyalar
- `index.html` — sayfa
- `style.css` — tasarım
- `script.js` — menü ve demo randevu etkileşimleri

## Yayın öncesi
Görsel lisanslarını, mobil görünümü ve erişilebilirliği tarayıcıda ayrıca kontrol edin.
